#deskdeck

So im creating a desk companion with which u can control various task assigned to the deck

# Repository Structure
- `/cad` - 3D enclosure models and STEP assembly files.
- `/pcb` - KiCad schematic, board layout, and manufacturing Gerbers.
- `/firmware` - ESP32-S3 Arduino C++ source code

- # Features
- Native USB HID keyboard & media control via ESP32
- 4 programmable mechanical key
- EC11 rotary knob for volume with click-to-mute
- 0.96" I2C OLED display for mode and status feedback(currently optional)
- 15-degree angled 3D-printed enclosure
